# Lab 6 - Morphological Operations

## Overview
This lab demonstrates basic morphological operations in image processing using OpenCV.  
The operations were applied using both square and circular kernels to compare their effects on image shapes and noise removal.

## Operations Used
- Erosion
- Dilation
- Opening
- Closing

## Task 1
Applied morphological operations using a square kernel.

### Results
- Erosion reduced object size.
- Dilation expanded objects.
- Opening removed small noise.
- Closing filled small gaps.

## Task 2
Applied the same operations using a circular kernel.

### Results
- The output appeared smoother.
- Rounded objects were preserved better compared to the square kernel.
